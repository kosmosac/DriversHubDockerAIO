# Credits and source repositories

The frontend footer retains the original Drivers Hub attribution and opens a
compact **Credits & source** dialog. It links to the public source repositories
used by this deployment:

- HubFrontend
- HubBackend
- DriversHubDockerAIO

The frontend also derives a link to each GitHub repository's contributor
overview. These entries describe the delivered software and cannot be changed
through the Hub administration interface.
